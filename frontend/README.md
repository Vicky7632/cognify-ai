# Frontend

The planned client is a React, TypeScript, Vite, and Tailwind CSS application. No frontend package manifest, app code, or dependencies exist yet.

When the frontend phase begins, keep provider/database credentials out of browser code; only a non-secret API base URL belongs in client-side configuration. Connect to the versioned Cognify API (`/api/v1`) and handle uploads, processing, and API failure states explicitly.

Setup instructions and test commands will be added when the stack is selected.
